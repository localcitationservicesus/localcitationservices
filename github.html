This supporting page for Local Citations Services, published as a GitHub Pages mirror, makes the case for selection over volume: general directories that people actually use, niche directories for your trade, and local directories for the communities you serve.

A long report full of dead or irrelevant directories does not help a business. What helps is a shorter list of live, relevant listings with consistent details — name, phone, website, and a service description that matches what you actually do. That is the standard applied to every directory submission, and it is why the delivery report lists each directory and its status instead of hiding behind a total count.
